# DiPlay Seal HUD — 2022 款海豹导航适配

基于 [DiPlay v0.2.10](https://github.com/shihabal3amri/DiPlay/releases/tag/v0.2.10) 的社区修改版，针对 **2022 款比亚迪海豹 EV 700km、DiLink 4.0／Android 10** 的旧版原厂导航接收服务进行适配。

**已验证：CarPlay 高德 → HUD 转向提示、仪表「简易导航」提示。未完成：仪表小地图／全屏地图的手机路线同步。** 本项目不是比亚迪、高德或 Apple 官方产品，不是原厂高德定制版的替代品。

## 开发场景与问题

车主希望继续使用 iPhone 上的高德，通过 DiPlay 在中控显示 CarPlay，同时在原车 HUD 和方向盘后的仪表上看到相同导航提示。原车定制高德的仪表底图会继续运行，但 CarPlay 高德开始导航后，这张底图没有手机规划路线。

该车机使用旧服务 `com.example.amapservice`，原版适配未识别这个环境。接通旧服务后，HUD 已能显示方向，仪表简易导航也出现箭头和道路名称，但距离、剩余路程及时间曾显示为 `-1`。本版补齐旧服务需要的文字字段。

## 目前效果

| 显示区域／模式 | 本版状态 | 说明 |
| --- | --- | --- |
| 中控 CarPlay 高德 | 沿用上游能力 | 手机路线在中控显示 |
| 前挡风玻璃 HUD | 车主已验证可用 | 同步手机导航方向等提示；不宣称投射完整地图 |
| 仪表「简易导航」 | 车主已反馈全部显示正常 | 箭头、道路名称、路口距离、剩余距离及时间 |
| 仪表「小地图／小屏导航」 | **手机路线未同步** | 仍由原车高德提供底图；看到地图不代表已接通 CarPlay 路线 |
| 仪表「全屏地图／全屏导航」 | **手机路线未同步** | 同上，不提供原生高德般的完整路线显示 |

**简易导航与小地图是两个模式。** 简易导航显示转向和文字；小地图显示地图画面。本版接通的是提示数据通道，没有把手机的完整路线写进原车高德，也没有替换原车地图画面。完整地图曾做过实验，未达到可交付效果；本次发布的 Test2 不包含该实验。

## 修改内容

1. 新增旧版海豹服务选择器：识别指定系统指纹及原厂接收服务，保留上游新服务 `com.byd.amapservice` 路径。
2. 在 Android 包可见性声明中加入 `com.example.amapservice`，使适配服务可被检测。
3. 将 CarPlay 导航提示通过现有标准导航广播交给旧版原厂接收服务，使 HUD／简易导航获得提示。
4. 为旧服务补齐 `SEG_REMAIN_DIS_AUTO`、`ROUTE_REMAIN_DIS_AUTO`、`ROUTE_REMAIN_TIME_AUTO`，按米／公里、分钟／小时格式显示，修复有数值却显示 `-1` 的问题。手机未提供数值时发送空文字，不编造距离或时间。
5. 使用独立包名和应用名称，与原版区分；新增旧服务适配及导航字段回归测试。

没有合并此前音量、USB 重复确认或完整地图实验修改。详见 [修改记录](CHANGELOG.md) 和 [适配范围](COMPATIBILITY.md)。

## 适配范围

目前仅有一辆车的反馈：**2022 款海豹 EV 700km，DiLink 4.0／Android 10，系统版本 `21.1.2.2601210.1`**；原厂旧接收服务版本号 `10502002`。

代码还核对对应系统指纹和系统应用标志。**同为海豹、同为 Android 10，都不代表一定适配。** 不同固件、年款及其他比亚迪车型尚未验证；未验证环境不会强行启用此旧服务适配。上游已有其他接收路径不在本次实车验证范围内。

## 安装与使用

1. 停车挂 P 挡，把 APK 传到车机，用文件管理器打开，按系统提示允许安装。
2. 打开 **DiPlay Seal HUD**，进入“设置 → 比亚迪导航”，保持“HUD和仪表盘导航”开启，连接 iPhone。
3. 用方向盘操作将仪表切换为 **简易导航**，在 CarPlay 高德中开始导航。
4. 检查方向、路名和距离；结束导航后确认提示清除。避免同时运行两个 DiPlay。

**手动安装、基本 CarPlay，以及本版的 HUD／简易导航适配通道均不依赖 ADB。** 车机需允许外部 APK 安装。电量、车轮速度、仪表歌曲等标注“需要 ADB”的上游功能需另行开启 ADB。

新安装不会携带原车主的配对和设置，需自行连接 iPhone。较高版本的 `.sealhud` 实验包不能直接被此版本降级覆盖；如需卸载后安装，应先记录设置，卸载会清除该应用的数据。
